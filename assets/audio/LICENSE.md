# Audio licence

Every sound in this folder is synthesized from code by `tools/audio/build_sfx.py` (square,
triangle and sine voices, filtered noise). No third-party samples, recordings or packs are used.

The sounds belong to the Dust In Space project and share its licence. To change one, edit its
builder in `tools/audio/build_sfx.py` and run `python tools/audio/build_sfx.py`: the output is
seeded, so an unchanged cue rebuilds to the same file.
